# classification-algorithms-comparison
Comparison of Logistic Regression, Decision Tree, Random Forest, SVM, KNN, and Naive Bayes using the Iris dataset and Precision, Recall, and Accuracy metrics.
Comparison of Classification Algorithms

## Aim
To implement and compare multiple machine learning classification algorithms on a common dataset and evaluate their performance using Precision, Recall, and Accuracy.

## Objectives
1. To understand different machine learning classification algorithms.
2. To apply multiple classifiers to the same dataset.
3. To calculate Precision, Recall, and Accuracy for each classifier.
4. To compare the results and identify a suitable algorithm for the selected problem.

## Problem Statement
Classify Iris flowers into three species—Setosa, Versicolor, and Virginica—using sepal and petal measurements. Compare six classification algorithms based on their predictive performance.

## Dataset
- **Dataset:** Iris Dataset
- **Source:** Scikit-learn built-in dataset
- **Features:** Sepal length, sepal width, petal length, and petal width
- **Target classes:** Setosa, Versicolor, and Virginica

The Iris dataset is a commonly used dataset for learning and evaluating classification algorithms.

## Algorithms Implemented
1. **Logistic Regression:** Uses a logistic function to estimate class probabilities.
2. **Decision Tree:** Classifies data using a tree of decision rules.
3. **Random Forest:** Combines multiple decision trees to improve generalization.
4. **Support Vector Machine (SVM):** Finds decision boundaries that separate classes.
5. **K-Nearest Neighbors (KNN):** Predicts a class using the nearest training samples.
6. **Naive Bayes:** Uses Bayes' theorem with a conditional independence assumption.

## Methodology
1. Load the Iris dataset.
2. Separate the input features and target labels.
3. Split the dataset into training and testing sets.
4. Standardize the features for algorithms that benefit from scaling.
5. Train all six classification algorithms.
6. Predict the species of the test samples.
7. Calculate Precision, Recall, and Accuracy.
8. Compare the performance of all models.

## Evaluation Metrics

### Accuracy
Measures the proportion of all predictions that are correct.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

### Precision
Measures how many predicted positive cases are actually positive.

Precision = TP / (TP + FP)

### Recall
Measures how many actual positive cases are correctly identified.

Recall = TP / (TP + FN)

For this multiclass classification problem, **macro-averaging** is used to calculate Precision and Recall across all three species.
